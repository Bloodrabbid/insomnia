Привет! Проблема заключается в том, что папка `dist` (в которой находится скомпилированный код плагина) игнорируется гитом, так как она попадает под правило `dist` в вашем корневом `.gitignore` (строка 34).

Когда ваш друг склонировал исходники, он получил только исходный код плагина (папку `src`, `package.json` и файлы конфигурации), но не скомпилированный файл `dist/index.js`, который ищет Insomnia при запуске. 

Поскольку плагин указан как локальная зависимость (`file:./src/plugins/...`) и не является частью общих рабочих областей (workspaces) в корневом `package.json`, его зависимости и сборка не запускаются автоматически при сборке проекта.

### Как другу запустить это прямо сейчас:
Ему нужно вручную собрать плагин перед запуском или сборкой самой Insomnia. Пусть он выполнит в терминале из корня проекта:

```bash
cd packages/insomnia/src/plugins/insomnia-plugin-universal-git
npm install
npm run build:prod
```
После того как в папке плагина появится директория `dist`, меню плагина снова станет видимым.

### Как исправить это в вашем репозитории (чтобы работало у всех "из коробки")

У вас есть два пути решения:

**Вариант 1 (простой): Закоммитить собранный плагин в Git**
Разрешите гиту отслеживать папку `dist` именно для этого плагина. Для этого добавьте в конец корневого файла `.gitignore` исключение:
```gitignore
!packages/insomnia/src/plugins/insomnia-plugin-universal-git/dist/
```
Затем соберите плагин у себя локально и сделайте коммит появившейся папки `dist/`.

**Вариант 2 (правильный): Автоматизировать сборку плагина**
Если вы хотите, чтобы плагин собирался из исходников вместе со всем проектом:
1. Добавьте путь к плагину в секцию `workspaces` в самом корневом `package.json`:
   ```json
   "workspaces": [
     // ... другие workspace
     "packages/insomnia/src/plugins/insomnia-plugin-universal-git"
   ]
   ```
2. И добавьте вызов скрипта сборки плагина в `postinstall` или `build` корневого `package.json` (или `packages/insomnia/package.json`), например: `npm run build:prod -w insomnia-plugin-universal-git`.
